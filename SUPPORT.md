# Support

Where to go depending on what you need:

- **Questions & ideas** → open a **Discussion** on the repository (if enabled), or
  a question issue.
- **Bug reports & feature requests** → open an **Issue** using the provided
  templates.
- **Security vulnerabilities** → **do not** open a public issue. Follow
  [`SECURITY.md`](SECURITY.md) (private reporting).

Please remember these projects are maintained on a **best-effort** basis by a
single maintainer, so responses may take some time. Searching existing issues and
discussions first is the fastest way to find an answer.

---

# サポート（日本語）

用途に応じた窓口:

- **質問・アイデア** → リポジトリの **Discussions**（有効な場合）、または質問用 Issue。
- **バグ報告・機能要望** → 用意された**テンプレートを使って Issue** を作成。
- **セキュリティ脆弱性** → 公開 Issue を立て**ない**でください。
  [`SECURITY.md`](SECURITY.md) に従って非公開で報告してください。

これらのプロジェクトは単独メンテナが**ベストエフォート**で維持しているため、
返信に時間がかかる場合があります。まず既存の Issue / Discussions を検索すると
最も早く答えが見つかります。
