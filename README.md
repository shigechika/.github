# .github

Default community health files for [@shigechika](https://github.com/shigechika)'s repositories.

Files in this repository act as **organization/account-wide defaults**: any repository
under `@shigechika` that does not provide its own version of one of these files
inherits the version defined here. A repository can always override a default by
committing its own copy.

See GitHub's documentation on
[creating a default community health file](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## What is (and isn't) inherited

**Inherited from this repo** (human-facing documents & templates):

- `SECURITY.md` — vulnerability reporting policy
- `CONTRIBUTING.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`
- `.github/FUNDING.yml`

**NOT inherited** (must live in each repository):

- `.github/workflows/` — GitHub Actions workflows
- `.github/dependabot.yml`
- `.github/copilot-instructions.md`

# .github（日本語）

[@shigechika](https://github.com/shigechika) の各リポジトリ向けの
**デフォルト community health files** です。

このリポジトリに置いたファイルは**アカウント全体の既定値**として働きます。
`@shigechika` 配下で自前のファイルを持たないリポジトリは、ここで定義したものを継承します。
各リポジトリは自前のコピーを置けばいつでも上書きできます。

**継承されるもの**（人間向けの文書・テンプレート）: `SECURITY.md` /
`CONTRIBUTING.md` / `SUPPORT.md` / `CODE_OF_CONDUCT.md` /
`.github/ISSUE_TEMPLATE/` / `.github/PULL_REQUEST_TEMPLATE.md` / `.github/FUNDING.yml`

**継承されないもの**（各リポジトリに置く必要がある）: `.github/workflows/`（Actions）/
`.github/dependabot.yml` / `.github/copilot-instructions.md`
